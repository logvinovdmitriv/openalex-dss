# Научная апробация

В этой папке хранятся зафиксированные материалы научной апробации программного комплекса. Это не runtime-данные и не временные выгрузки, а подготовленный доказательный пакет для включения в выпускную работу.

## Доступный апробационный срез

- [Прикладная математика, 2020-2024](прикладная_математика_2020_2024/README.md)

## Что считается доказательным материалом

Внутри каждого среза должны быть:

- паспорт среза;
- доказательная Excel-книга;
- аналитический отчет;
- каталог рисунков;
- подписи к рисункам;
- правила доказательности и размещения графиков;
- PNG-версии рисунков для вставки в текст;
- SVG-версии рисунков для редактирования и печатной верстки;
- контрольные суммы файлов пакета.

## Терминологические правила

В материалах используется формальная русскоязычная терминология:

- «базовые показатели»;
- «дополнительная метрика», а не утверждение о замене общепринятых индексов;
- «ранговая корреляция Спирмена»;
- «описательная статистика»;
- «ящик с усами»;
- «сдвиг ранга»;
- «пересечение верхних N позиций»;
- «проверка допуска к анализу»;
- «полный отфильтрованный серверный срез».

Каждый содержательный вывод должен быть связан с числом, таблицей или рисунком и ограничением интерпретации.
