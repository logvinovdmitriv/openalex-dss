## 4. Описательная статистика показателей

Базовый контур-показатели: `P`, `C`, `C_frac`, `h`, `i10`, `g`.
Дополнительный контур-показатель: `IUPV-S`.

Ключевые наблюдения:

- `P`: медиана `1`, третий квартиль `2`, максимум `263`; большинство авторов имеют малое число работ в срезе.
- `C`: медиана `1`, третий квартиль `5`, максимум `5854`; распределение имеет выраженный тяжелый хвост.
- `C_frac`: медиана `0.5`, третий квартиль `2`, максимум `1549.64`; дробный учет снижает масштаб цитируемости, но тяжелый хвост сохраняется.
- `h-индекс`: медиана `1`, третий квартиль `1`, максимум `46`; показатель устойчив, но имеет очень высокую долю совпадающих значений.
- `i10-индекс`: доля нулевых значений `87.38%`; для данного локального среза показатель слишком груб для различения большинства авторов.
- `g-индекс`: медиана `1`, третий квартиль `1`, максимум `69`; близок к `h`, но сильнее реагирует на высокоцитируемые работы.
- `IUPV-S`: медиана `22.26`, третий квартиль `58.33`, максимум `100`; показатель задает процентильную шкалу робастного долевого цитируемого вклада.

Диаграмма «ящик с усами» построена по точным квартильным статистикам. Для читаемости использована шкала `log10(1+x)`, правый ус ограничен P95; максимумы, IQR и число выбросов сохранены в Excel-листе «Описательная статистика».

## 5. Согласованность индексов

Ранговые корреляции Спирмена показывают, какие показатели дают близкие ранжирования, а какие фиксируют отличающиеся аспекты авторского профиля.

| Пара показателей | Spearman |
| --- | ---: |
| `C` и `C_frac` | 0.980 |
| `h` и `g` | 0.979 |
| `C_frac` и `IUPV-S` | 0.998 |
| `h` и `IUPV-S` | 0.933 |
| `P` и `IUPV-S` | 0.577 |
| `i10` и `IUPV-S` | 0.543 |

Интерпретация: `IUPV-S` ожидаемо близок к `C_frac`, потому что строится на логарифмированной сумме долевых citation credits. При этом логарифмическое сглаживание и процентильная нормализация меняют локальные ранги относительно `h`, особенно вне верхнего ядра рейтинга.

## 6. IUPV-S как дополнительная метрика

`IUPV-S` не входит в базового контура. Это дополнительная авторская дополнительная метрика для проверки робастного долевого цитируемого вклада.

Проверки `IUPV-S`:

- В таблице `ratings` есть строки `metric_name = iupv_s`.
- Положительные значения `IUPV-S` имеют `74424` автора.
- Нарушений правила `rfi_log_frac <= 0 => iupv_s = 0` не обнаружено.
- Пересечение top-100 с `h-индексом`: `70` авторов из `100`.
- Медиана абсолютного сдвига ранга относительно `h`: `1031`.
- P90 абсолютного сдвига ранга относительно `h`: `10411`.

Вывод: `IUPV-S` не является независимой от цитируемого вклада метрикой. Ее корректно описывать как сглаженный дробный показатель цитируемого вклада с понятной шкалой 0-100, а не как универсальную замену базовых показателей.

## 9. Ограничения интерпретации

- Срез относится только к прикладной математике за 2020-2024 годы и не должен автоматически обобщаться на все области науки.
- `IUPV-S` является дополнительной метрикой и не заменяет базовый набор `P`, `C`, `C_frac`, `h`, `i10`, `g`.
- Записи без `author_id` и дублирующиеся записи авторства отражают ограничения исходных данных OpenAlex.
- Загрузка через API cursor не запрашивает `authors_count` через Works `select`, потому что OpenAlex отклоняет это поле для списочных запросов. Для данного среза это не заблокировало финальный анализ: усеченных работ и флагов несовпадения числа авторов не обнаружено.
