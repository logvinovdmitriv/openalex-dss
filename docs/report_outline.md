# Report Outline

Рекомендуемая структура аналитической записки по результатам запуска DSS.

## 1. Источник данных и срез

- источник OpenAlex;
- `slice_id`, `dump_id`, `run_id`;
- предметный фильтр;
- период;
- типы работ;
- режим XPAC/retracted/paratext;
- выбранный `fraction_mode`.

## 2. Нормализация и качество данных

- число raw works;
- число работ после локальных mart-фильтров;
- число authorships;
- число авторов с индексами;
- quality flags;
- truncated authorships и результат backfill/exclusion policy.

## 3. Базовые индексы

Описать только core-набор:

```text
P, C, C_frac, h, i10, g
```

Для каждого показателя указать назначение, распределение, zero-rate, tie-rate
и ограничения интерпретации.

## 4. Сравнение рангов

- Spearman/Kendall между core-метриками;
- top-N overlap;
- rank-delta относительно `h`;
- отдельное сравнение `C` и `C_frac` как эффект соавторства.

## 5. IUPV-S как дополнительная формула

Описать формулу:

```text
RFI(a) = Σ log1p(cited_credit_i)
IUPV-S(a) = 100 * percentile_rank(RFI(a))
```

Зафиксировать, что это extension-метрика, а не замена core-набору. Показать:

- распределение IUPV-S;
- связь с `h`, `C_frac`, `g`;
- top-N overlap с baseline;
- rank shifts;
- чувствительность к выбросам и соавторству.

## 6. Ограничения

- локальность среза;
- качество OpenAlex metadata;
- author disambiguation;
- возраст публикаций;
- ограничения выбранного fraction mode.

## 7. Выводы СППР

Формулировать выводы как рекомендации в пределах выбранной задачи:

- какой core-показатель использовать как baseline;
- когда нужен `C_frac`;
- как интерпретировать IUPV-S;
- какие ограничения должны сопровождать рейтинг.
