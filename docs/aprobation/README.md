# Архивный пакет апробации

Эта папка содержит ранний технический пакет апробации от `2026-05-11`.
Он сохранен как архив воспроизводимости и не является основным материалом
для демонстрации или текста выпускной работы.

Основной русскоязычный пакет научной апробации находится здесь:

```text

```

При подготовке аналитической записки используйте основной русскоязычный пакет,
а материалы из `docs/aprobation/2026-05-11` рассматривайте как техническую
историю предыдущего запуска.
